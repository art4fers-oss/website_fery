WEBSITE PROFIL FERY RAHMANTO - RESPONSIVE
===========================================

Perbaikan:
- Responsive mobile/tablet/desktop.
- Menu hamburger di HP/tablet.
- Semua halaman memakai tema Galeri Siswa:
  #1e3a8a, #3b82f6, #dbeafe, #60a5fa.
- Navigasi Home, Profil, Keahlian, Pengalaman, Portofolio,
  Galeri Siswa, Kontak, dan Admin.
- Galeri Siswa: Kelas 7 sampai Kelas 12; Galeri Foto dan Galeri Video.
- Admin: upload/edit/hapus foto dan video, tambah/edit/hapus link website,
  ubah alamat website, WhatsApp, email, Instagram, Facebook.
- Foto/video upload disimpan di IndexedDB browser; video juga bisa berupa link YouTube/MP4.
- Pengaturan/link disimpan di localStorage browser.

ADMIN:
1. Buka admin.html.
2. PIN awal: 1234.
3. Setelah masuk, ganti PIN.
4. Upload foto/video dari HP atau komputer.
5. Buka galeri-siswa.html untuk melihat hasilnya.

CATATAN PENTING:
Sistem admin pada paket HTML ini adalah admin lokal/browser. Artinya data upload
tersimpan pada browser/perangkat tempat admin digunakan, bukan otomatis tersinkron
ke perangkat lain. Untuk website online dengan admin lintas perangkat diperlukan
backend/database dan autentikasi server.
